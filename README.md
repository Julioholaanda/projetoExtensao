# Sistema de Doações - ACNC

## 📌 Sobre o Projeto

Este projeto está sendo desenvolvido em equipe como parte de um projeto acadêmico de extensão.

O objetivo é criar um **site para facilitar doações** para a instituição **ACNC**, uma organização sem fins lucrativos.
A plataforma permitirá que doadores possam contribuir de forma simples e rápida, realizando doações de:

* dinheiro
* roupas
* brinquedos
* outros itens

A proposta do sistema é tornar o processo de doação **mais acessível, organizado e eficiente**, conectando pessoas que desejam ajudar com a instituição.

---

## 🎯 Objetivos do Sistema

O sistema terá como objetivos principais:

* Facilitar o processo de doação
* Permitir cadastro de doadores
* Registrar doações realizadas
* Organizar informações das doações
* Ajudar a instituição a gerenciar melhor os itens recebidos

---

## 🛠 Tecnologias Utilizadas

O desenvolvimento do projeto utiliza as seguintes tecnologias:

* Java (Backend)
* HTML5 (estrutura das páginas)
* CSS3 (estilização)
* JavaScript (interatividade)
* MySQL (banco de dados)

---

## 👥 Equipe

Este projeto está sendo desenvolvido em equipe para a disciplina de extensão.

---

## 📄 Finalidade

Este sistema tem finalidade **educacional e social**, com o objetivo de aplicar conhecimentos de desenvolvimento web enquanto contribui com uma causa social.
